# ViewSonic LS850WU Control Spec

## Summary
ViewSonic LS850WU WUXGA laser projector with RS-232 and LAN control interfaces. This spec covers the RS-232 command protocol. Serial config: 19200 baud default, 8N1, no flow control. Supports power control, source routing, image adjustment, lamp mode, and queryable status.

## Notes
RS-232 connector: DSUB 9-Pin male. Only 3 pins needed (RXD=pin2, TXD=pin3, GND=pin5). Crossover (null modem) cable required.

Supported baud rates: 4800/9600/19200/38400. Default: 19200.

Command packet format includes checksum. Every command receives a response.

LAN control uses same code format with port 4661 (note 2). Pro9 series uses port 23 for LAN control.

HDMI Range: Enhanced/Full = 0-255 steps; Normal/Limited = 16-235 steps.

When response code 0x00 0x14 0x00 0x00 0x00 0x14 has first byte 0x00, function is disabled (greyed out in OSD).

Error response status available for service debug (note 3) — 32 bytes total.
