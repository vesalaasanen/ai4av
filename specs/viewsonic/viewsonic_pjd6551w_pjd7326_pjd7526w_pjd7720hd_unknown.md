# Viewsonic PJD6551W / PJD7326 / PJD7526W / PJD7720HD Control Spec

## Summary
Viewsonic DLP projector family supporting RS-232 control. Protocol uses 10-byte hex command packets with 115200 baud 8N1 serial. Models span 3D sync, HDMI, lamp modes, extensive image geometry and color controls.

## Transport
```yaml
protocols:
  - serial
serial:
  baud_rate: 115200
  data_bits: 8
  parity: none
  stop_bits: 1
  flow_control: none
auth:
  type: UNRESOLVED
```

```yaml
- powerable
- routable
- queryable
- levelable
```
